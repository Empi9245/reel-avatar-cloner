## Quick-Start Workflow: Reference Video + Custom Modifications -> 1:1 `@Eva` Clone

Whenever the user sends a reference Reel/TikTok + `@Eva` (or another avatar) + custom changes (e.g., hide brand names, swap metrics, build separate IG/TikTok CTAs), read [references/artistic-direction-and-realism.md](./references/artistic-direction-and-realism.md) first and run these 6 steps:

1. **1:1 Concept & Framing Audit (`sheet_orig.jpg`):** Map every scene of the original video before generating anything — PIP card vs fullscreen placement, whether the speaker's head/hair breaks **3D out above the rounded PIP card**, chest-up shoulders/hands framing, and screen graphics (keep real B-roll via `temporal_4dof` or rebuild crisp vector cards 1:1 in Remotion).
2. **Apply User Modifications Upfront:** Scrub any forbidden brand name across spoken dialogue, kinetic captions, browser URL bars, terminal installs, brand squircles, and DM bubbles (`••••••••`), and split `clip_06` into separate **Instagram (`commenta`)** and **TikTok (`seguici sul profilo e scrivi promo` / `Scrivi in DM`)** takes.
3. **Single-Face Multi-Room & Credit-Safe Generation (`gflow-cli` / `H3`):** Check credits (`python scripts/gflow_batch_ingest.py check`), lock strictly to **one model at minimum tier** (`--model omni-1.2-flash --resolution 360p`, ~5 credits/clip, never switch to `veo-fast` mid-reel). Use [resources/eva_canonical_warm_armadio.png](./resources/eva_canonical_warm_armadio.png) as `@Eva`'s canonical anchor; if moving into a second room, generate Room B via `gen-room-anchor` (`i2i` Stills-First relighting) instead of passing two different face sheets into `r2v`, keep prompts concise (`< 200` words `MCSLA` + 5 Acting Laws), and checkpoint with the user before final clips when requested.
4. **Silence Trim + LAB Exposure + 4-Stage Voice Lock + 3D Alpha Pop-Out PIP:** Run `gflow_batch_ingest.py` (`trim --adaptive-loudnorm` -> `grade` `gamma=1.10` at **0 credits** -> `match-audio` 8-band EQ/`-14 LUFS`, plus single-pass concatenated ElevenLabs STS `elevenlabs_voice_ref.py --unify-dir` if API key configured -> `popout-pip` encoding `1036x850` `VP9 yuva420p` `.webm`). Never chop Eva's hair flat inside CSS `overflow: hidden`.
5. **Piecewise-Linear Audio-First Sync, J-Cuts & Handheld Camera Motion:** Map each sentence (`mapEvaFrame`) to Eva's real spoken length (`0.93x–1.06x` `atempo`), widen sub-1s fullscreen flashes to `1.1s–2.3s`, omit fake orange light-leaks, add `3–5f` audio J-cuts + subtle UI SFX (`-24..-28 dBFS`), and layer `<OffthreadVideo transparent />` + subtle handheld sway/tilt/zoom (`SpeakerPipAndFull.tsx`).
6. **Dual Render & Full Playback Audit:** Export separate `1080x1920 @ 30fps` Instagram and TikTok MP4s, inspect keyframe contact sheets AND play full MP4s via `read_file` before delivering.

## Core Principles

1. **Never regenerate B-roll / UI / motion-graphic screens in AI.** Keep real laptop/phone segments (recovering pixels via `temporal_4dof`) OR rebuild full UI/terminal/browser/kinetic-caption motion graphics 100% in **Remotion** (`1080x1920 @ 30fps`) so cards and typography are pixel-sharp (`0%` AI slop).
2. **Never use single-frame 2D Telea (`telea`) across moving laptop UI cards.** Telea pulls dark lines or adjacent card edges vertically, creating Voronoi/bubble distortions around replaced text. Always clean handheld/panning screen B-roll using **`mode: "temporal_4dof"`** (`cv2.estimateAffinePartial2D` donor alignment + ring illumination matching + horizontal scanline fallback for UI state/hover switches). Keep `telea` only for static pill interiors or Avatar reference clips sent to Google Flow.
3. **Stepped black rounded pills (`Genio: ...`) stay clean with exact overlap.** Clean the English pill pixels with `pill_telea` strictly *inside* the replacement black pill's outer coordinates so zero blurred Telea boundary is ever exposed.
4. **Always strip audio (`-an`) from all V2V reference clips** before uploading to Flow (save `audio_originale.mp3` separately; on final audio muxing NEVER use `-shortest`, so a slightly shorter MP3 never cuts off the last video frames).
5. **For Spoken Multi-Clip Reels (`<= 8s` per Flow chunk), ALWAYS follow the Pre-Sized V2V Duration Budget + Complete-Sentence Chunking + 2-Phase Star Workflow:**
   - **STRICT BAN on Boomerang Looping & Collar/Chest `Telea` Inpainting in V2V References (CRITICAL):** NEVER manufacture a fake 4–7s V2V clip by repeating/boomerang-looping a short `0.3s–2.0s` source fragment (`boomerang_pad`), and NEVER run `Telea` inpainting across the speaker's chest/neck/collar inside a V2V reference! Looping 10–30 frames looks robotic/glitchy ("tutto buggato") and leaves smudged `Telea` blobs that Flow copies. Only use **V2V** when a **real, continuous, unlooped `>= target_dur` clip** (zero cuts, zero flashes, zero male hands/rings, zero chest inpainting) genuinely exists (verified by playing the `.mp4` via `read_file`, NOT just static contact-sheet stills!).
   - **When Source Cuts Are `< 3s` (UI-Split Reels Like Reel 11) — Two Clean Routes Only:**
     1. **Primary (`Ingredients` — Images Only, NO Looped Video):** Attach `resources/eva_con_tshirt.png` (+ optional clean hand-free room `master_*.png` in Phase B) + `Add Voices / @Voice` with **NO V2V video uploaded**. Unlocks Flow's manual duration selector (`3–10s` Free / `3–15s` Plus+), generates smooth continuous organic motion, and avoids duration lock, male hands, and loop glitches.
     2. **True V2V Motion Route (Only If Genuine Unlooped `6–8s` Motion Video Exists):** Use either a continuous unlooped real creator take (`>= target_dur`, zero hands/mic) or a clean continuous 6–8s silent-acting reference clip (`target_dur = max(3.8, words / 2.5 + 0.5, syllables / 4.7 + 0.5)` -> `4.2s–7.2s`, splitting dense sentences `> 7.5s` at commas).
   - **Audio-First Remotion Timing (Never `atempo`-Crush Clean Voiceover):** Never squeeze Eva's calm Italian clips back into shorter English slots with aggressive `atempo > 1.08`; adapt Remotion `<Sequence>` windows, UI cards, `OutroBlackCard`, and `KineticCaption.tsx` cues to fit Eva's real spoken clip durations cleanly.
   - **Never cut talking-head chunks mid-clause:** Split only at complete sentences or grammatical comma boundaries (`4.2s–7.2s` <= 8s) for Flow, and in Remotion splice normalized spoken audio across cards while aligning PIP/fullscreen video cuts cleanly to Eva's real speech beats.
   - **Always dress `@Eva` BEFORE Flow (`resources/eva_con_tshirt.png`)**: `eva_front_single.png` ends at the neck and causes wardrobe drift between scenes.
   - **Send Phase A Prompts FIRST (1 master clip per unique room background — NEVER dump all 6 prompts at once!)**: Wait for the user's generated masters (`eva_01`, `eva_04`), verify eyes/hands/speech (`"10-20"` spelled out `"dalle dieci alle venti ore"`), extract hand-free master room stills (`master_*.png`), and THEN send Phase B prompts anchored to those masters (`eva_con_tshirt.png` + `master_*.png` + `@Voice`, or Flow `Frames`/`Extend`, or a verified unlooped V2V clip — NEVER re-upload PC-encoded Eva MP4s with altered speech or Flow triggers `?p=speech_edit`).
   - **Video Playback Audit Before Delivery:** Always play every prepared `.mp4` reference directly with `read_file` (never rely only on static contact sheets) to verify smooth continuous human motion, zero loop tic, zero chest/neck smudges, zero male hands/rings, and open eyes before spending credits; omit `"hand gestures of the attached driving reference clip"` + `"small silver hoop earrings"` from prompts, and specify `with graceful female hands and neat natural fingernails` + bespoke feminine gestures per clip + `no extra or warped fingers, no rings`.
   - **Voice Unification Backup & Local Unsloth MiniMax-H3 Option:** If slight vocal timbre drift occurs across rooms, clone Eva's voice (`python scripts/elevenlabs_voice_ref.py --clone-voice Eva --save-env`) and batch-unify all clips via Speech-to-Speech (`python scripts/elevenlabs_voice_ref.py --unify-dir <eva_clips_dir>` or `ingest_eva_clips.py --dir <eva_clips_dir> --unify-elevenlabs`), preserving exact millisecond lip timing — zero Flow re-roll credits wasted. For 100% local/offline zero-filter video generation with native voice cloning (`--ref-audio`), run [scripts/unsloth_h3_video.py](./scripts/unsloth_h3_video.py) (`MiniMax-H3 Ref2VA`), or use [scripts/gemini_veo_video.py](./scripts/gemini_veo_video.py) for direct Veo generation via `GEMINI_API_KEY` — see [references/multi-clip-consistency-and-local-h3.md](./references/multi-clip-consistency-and-local-h3.md).
6. **Prevent "Fake AI Eyes" BEFORE generating:** Inspect the reference clip's exact gaze trajectory, always apply the **Head-Lead Rule** + **Single-Target Gaze Lock** + `camera-left / camera-right` viewer coordinates, and never contradict the reference video's gaze direction.
7. **Google Flow Web vs Direct `gemini-omni-1.2-flash` API vs Manual Speed:** Google Flow Web (`labs.google/fx/tools/flow`) itself uses browser OAuth cookies, so automating clicks via the browser subagent is slow compared to pasting Star-Topology prompts manually (~2 min). **However, if `GEMINI_API_KEY` is configured**, the installed **`gemini-omni-flash-api`** plugin runs **`gemini-omni-1.2-flash` directly via the Gemini Interactions API (`google-genai >= 2.30.1`)** with `--first-frame`, `--image` (PNG references only — avoiding EEA/UK/CH `--video-reference` upload restrictions!), `--aspect-ratio 9:16`, `--resolution`, `--duration 3..15`, and parallel `--batch`! Alternatively, use `scripts/gemini_veo_video.py` (Veo) or local `MiniMax-H3 Ref2VA` (`scripts/unsloth_h3_video.py`). Only automate browser clicks when explicitly asked.
8. **NEVER reveal the promoted app name (`Freebuff` / `#freebuff`) in social captions, hashtags, or CTA text.** Wait: when cloning an explicit app explainer video whose cards/speech name the app, keep on-screen/audio faithful if requested, while social captions/CTA still protect the curiosity gap (`seguici e commenta "promo"`). Keep captions natural (`ig-human` verified: 0 machine tells, <= 3–4 hashtags, `ADV` + AI-generated disclosure).
9. **CTA differs by platform:** Instagram/Facebook = `commenta "promo"` (auto-DM via LinkDM). TikTok has no comment-to-DM (API limit, EU accounts restricted), so the TikTok cut uses `scrivimi "promo" in DM` and the user replies to DMs manually or with native auto-replies. Render a separate TikTok variant of the final reel. Details and the DM message: [references/cta-and-dm-funnel.md](./references/cta-and-dm-funnel.md).
10. **Dual Audio Discovery Strategy:** Always provide both:
    - **Metodo 1 (Ricerca Diretta Suono Meme):** In app su TikTok/IG, scheda "Suoni", cercando il testo dell'hook (es. `"genio tre desideri"`) si trova il suono già pre-tagliato dalla community per quel trend.
    - **Metodo 2 (Brano Ufficiale + Forbici ✂️):** Titolo ufficiale Shazam + offset Forbici al millisecondo (es. `Took Her To The O` a `00:07.86`). Dettagli: [references/audio-and-sound-matching.md](./references/audio-and-sound-matching.md).

## Voice Consistency & Character Reference Workflow (Fasi A–E)

**Trigger this 5-phase workflow** every time we:
1. Create a new avatar,
2. Update an avatar's voice, outfit, or reference sheet, or
3. Generate any spoken avatar video (via Seedance 2.5 / Higgsfield or talking-head scenes).

Full verbatim prompt templates, Italian/English/Korean pangrams, and Shot Caller v2 rules live in [references/voice-and-character-reference.md](./references/voice-and-character-reference.md).

### Fase A — Scheda Personaggio a 3 Pannelli (stile `Cast Kit v1`)
- If the avatar does not yet have a full 3-panel character reference sheet (for `@Eva`, adapt her existing `resources/eva_front_single.png` + `resources/eva_turnaround_1.jpg`), generate the Nano Banana Pro prompt for a **3-panel character reference sheet** on a **flat 18% neutral gray field** (shadowless, zero baked-in light, preserving true natural skin tones):
  - **LEFT:** full-body front, **headless** (Variant A ghost mannequin for crew/mock/collar necklines; Variant B clean neck cut for open necklines) with dead-on orientation lock.
  - **CENTER:** full-body rear, head attached, dead-on orientation lock + skin-tone consistency line.
  - **RIGHT:** tight chest-up face close-up, dead-on frontal.
- Include the `PHOTOREAL FLAT CLOSE` block verbatim from [references/voice-and-character-reference.md](./references/voice-and-character-reference.md).

### Fase B — Pangramma Fonetico + ElevenLabs v4 Audio Tags (stile `Voice Sheet v1`)
- Ask or deduce from the reference video:
  1. **Spoken language** (e.g., Italian, English, Korean, etc.).
  2. **Character & emotional range** (2–3 adjectives, e.g., natural/conversational, energetic, ironic, whispered, angry, emotional).
- Write a **phonetic pangram** in that language (2–4 natural clauses landing at 8–15s, covering all phonemes, vowels, diphthongs, geminates/doppie, and rich in closed-lip consonants `p, b, m` for visible lip seals).
- Insert **ElevenLabs v4 Audio Tags** directly inline (`[curious]`, `[excited]`, `[whispers]`, `[laughs]`, `[sighs]`, `[pause]`, `[softly]`, `[serious]`, `[gasps]`, one tag per clause) + expressive punctuation (`...`, `—`), without changing the base pangram words, and provide a Voice Design description (`"recorded close in a quiet room"`).

### Fase C — Generazione Audio ElevenLabs + Export MP4 in Secondi Interi
- Use [scripts/elevenlabs_voice_ref.py](./scripts/elevenlabs_voice_ref.py) (`eleven_v4` default, `eleven_v3` fallback/override, cross-language support for any `voice_id` in the ElevenLabs catalog):
  ```bash
  python scripts/elevenlabs_voice_ref.py --text-file <workdir>/pangram_tagged.txt --language it --min-seconds 5 --out-dir <workdir>
  ```
- **Mandatory Credential Gate:** The script reads `ELEVENLABS_API_KEY` and `ELEVENLABS_VOICE_ID` from `.env` (template: [.env.example](./.env.example)). **If either is missing, STOP immediately and ask the user for their ElevenLabs API key (and Voice ID) before proceeding**, while displaying the tagged pangram + Voice Design description ready to paste into the free ElevenLabs Web UI (if they generate the `.mp3` on the web, convert it with `--audio-in <file.mp3>`).
- Automatically measures exact MP3 duration via `ffprobe`, pads trailing silence up to **`math.ceil(duration)` exact whole seconds** (e.g., `15.2s` -> `16.00s` exact, never decimals), and exports `reference_voce.mp4` (`1280x720`, H.264, AAC).

### Fase D — Prompt per Video Reference Sheet a 1080p (stile `Shot Caller v2`)
- Send the Shotcaller pre-prompt check, then output the **1080p Seedance 2.5 / Higgsfield** split-screen prompt attaching:
  - `Image 1` (or Element handle): the 3-panel character sheet from Fase A.
  - `Video 1`: `reference_voce.mp4` (`T` exact whole seconds, sole audio source).
- Layout on a flat 18% neutral gray field:
  - **RIGHT panel (`1` continuous shot, `T`s, `18° / 120mm`):** close-up lip-syncing the pangram verbatim (tags stripped in `THE SPEECH IS THE PRIMARY SUBJECT` + explicit `b/p/m` lip-seal word list), turning the head `15–20°` either side of front to show bone structure and expressing every emotional tag beat.
  - **LEFT panel (`n = min(7, T // 2)` shots; Shot 1 = `T - 2*(n-1)`s, Shots `2..n` = `2s` each):** full-body turn (`84° / 24mm`) + tight outfit/accessory detail inserts (`12° / 180mm`), mouth closed.
- Instruct the user to save the rendered 1080p clip as a **Higgsfield Element** (e.g., `@eva-voice-ref`).

### Fase E — Uso nelle Scene Successive del Video
- Whenever generating prompts for real scenes (cloning a Reel or creating new spoken avatar videos), **always attach the saved Video Reference Sheet Element (`@[handle]`) as the primary character reference** and include:
  1. `THE REFERENCE LOCKS LOOK, VOICE AND PERFORMANCE — CRITICAL:` block right after `THE SCRIPT` (locks voice timbre, register, pitch, texture, pace, accent, facial expressiveness, and outfit, while blocking gray backdrop/panel/pangram leakage).
  2. In `ASSETS`: `Voice: exactly the voice heard in the reference.`
  3. In `AUDIO`: open every spoken line with `"her reference voice,"` (or `"his/their reference voice,"`) for generated speech, or use `@video1` whole-second attached-track lipsync (`THE SPEECH IS THE PRIMARY SUBJECT`).
  4. Never put character names, aspect ratios, or negative prompt blocks inside the prompt code block.

## Phase 1 — When the User Uploads a Reference Video to Clone

Create a clean working directory inside the project (e.g. `freebuff-export/<campaign-slug>/`) and run:

1. **Inspect & analyze exact frame boundaries (including subtle screen cuts & whip-pans):**
   - Run:
     ```bash
     python scripts/reel_cloner.py analyze <source.mp4> --workdir <workdir>
     ```
   - Inspect `analysis.json` (`cuts` + OpenCV `diff_events`) AND check boundary frames (`read_file` + bright-outlined text pixel check) to catch:
     - **Subtle UI-to-UI cuts** that score `< 0.25` in FFmpeg scene detection (e.g., dark MacBook UI cutting to dark UI).
     - **Whip-pan transition frames** between UI cuts where no center caption appears in the original (`0..1`, `31..32`, `59`, `87..88`, etc.).
     - **Mid-clip text/pill switches** (e.g., quote disappearing and top pill changing right on the audio beat) and **UI popup/hover state changes** so `temporal_4dof` splits at state boundaries cleanly.
   - Split into mute (`-an`), normalized `720x1280` `30fps` segments:
     ```bash
     python scripts/reel_cloner.py split <source.mp4> --cuts "0:6.0,6.0:end" --scale 720x1280 --workdir <workdir>
     ```

2. **Measure exact bounding boxes (`x0,y0,x1,y1`) & clean B-roll with `temporal_4dof`:**
   - For **MacBook / PC B-roll**, write `clean_p2.json` with:
     - Separate `"mode": "temporal_4dof"` entries per sub-clip and per UI state (`start_frame`, `end_frame` 1-based), setting `"min_y"` if delicate UI text sits right above the label, `"track_y"` excluding browser chrome if a popup closes mid-clip, and `"force_horiz_x_lt"` on frames with a partial left-side hover state change.
     - Optional `"mode": "pill_telea"` keeping clean rects strictly inside the replacement Italian pill bounds.
   - Run:
     ```bash
     python scripts/reel_cloner.py clean <workdir>/clips/parte2_ref_raw.mp4 --out <workdir>/clips/parte2_clean.mp4 --config <workdir>/clean_p2.json
     ```
   - Clean any **Avatar** reference clip (`parte1_ref_clean.mp4`) using `mode: "telea"` / `pill_telea` so Flow inherits pose/lighting without text artifacts.
   - **Mandatory check:** Extract frames from every sub-clip (especially over bright UI cards) and view with `read_file` to verify zero distorted contours.

3. **Render translated Italian captions matched to original geometry (`captions_p2.json`):**
   - Measure the original English caption's exact **`cy_center`** (`(y0+y1)//2`) and height, then configure each Italian card to match (`font_size`, `cy_center`, `font: "arialbd"` or `segoeuib`) so the new text covers the cleaned band naturally and NEVER overlaps below-UI elements or leaves the old top/bottom strip exposed.
   - Match whip-pan skip frames (`start_frame` after motion blur settles) and staggered sub-CTA appearance frames; replace English CTAs (`(comment link)`) with `seguici e commenta "promo" / per ricevere l'app`.
   - For top pills, add a `"pill"` card (`"line1": "Genio:"`, `"emoji1": "stars_trio"`, `"line2": "hai ancora 3 desideri"`).
